The Physics of Digital Audio Quantification: Sample Rates, Bit Depths, Bitrates, and Storage Calculations

Determining storage capacity requirements for digital audio workstation (DAW) sessions, film sound design archives, broadcast streams, or music distribution platforms requires an exact mathematical understanding of Pulse-Code Modulation (PCM) structures. Unlike compressed text strings or vectorized media assets, uncompressed audio file sizes scale deterministically based on sampling frequency, quantization bit depth, channel configuration count, and playhead timeline length.

This comprehensive technical manual breaks down the formulas governing sample rate to file size calculations, compares lossless and lossy audio codecs, analyzes multi-channel recording setups, and explains the distinction between decimal and binary memory allocation models in sound engineering applications.

The Audio Data Rate Equation: The baseline uncompressed bit rate of standard PCM audio is defined as:
Bitrate (bits/sec) = Sample Rate (Hz) × Bit Depth (bits) × Channel Count
Dividing total generated bits by 8 yields the raw byte throughput per second required by audio recording interface drives.

Digital Audio Fundamentals: Sampling Frequency and Quantization Depth

Converting an continuous analog acoustic wave into discrete digital values requires two primary dimensional parameters:

1. Sample Rate (Temporal Resolution)

Sample rate, measured in Hertz (Hz) or kilohertz (kHz), defines how many instantaneous amplitude snapshots are captured per second. According to the Nyquist-Shannon sampling theorem, to capture an analog frequency spectrum accurately without aliasing distortion, the sampling rate must be at least double the highest acoustic frequency contained in the sound signal. For human hearing (which caps near 20 kHz), 44.1 kHz (CD standard) or 48.0 kHz (video and film production standard) provide complete bandwidth capture.

2. Bit Depth (Amplitude Resolution)

Bit depth determines the dynamic range and noise floor of the recorded signal. Each added bit provides approximately 6.02 dB of dynamic range resolution:

  • 16-Bit PCM: Yields $2^{16} = 65,536$ discrete amplitude steps, delivering a theoretical dynamic range of 96 dB. Standard for Red Book CD media.
  • 24-Bit PCM: Yields $2^{24} = 16,777,216$ amplitude quantization levels, offering 144 dB of dynamic range. Standard for professional studio recording, mixing, and film post-production.
  • 32-Bit Floating Point: Uses a 24-bit mantissa with an 8-bit exponent, providing over 1,500 dB of dynamic range. This makes clipping or internal digital overload impossible inside modern DAWs during processing.

Mathematical Foundations of Audio Storage Calculation

Calculating raw audio storage overhead requires computing total bit accumulation over time before converting bits into standard file size metrics:

Uncompressed PCM File Size Formula:
$$\text{File Size (Bytes)} = \frac{\text{Sample Rate (Hz)} \times \text{Bit Depth (bits)} \times \text{Channels} \times \text{Duration (seconds)}}{8}$$

For example, calculating the uncompressed storage footprint of a 3-minute 30-second (210 seconds) stereo song recorded at 24-bit / 96 kHz yields:

$$\text{Total Bytes} = \frac{96,000 \times 24 \times 2 \times 210}{8} = \frac{967,680,000}{8} = 120,960,000 \text{ Bytes}$$

Converting bytes to decimal megabytes ($120,960,000 / 10^6$) yields 120.96 MB, whereas converting to binary mebibytes ($120,960,000 / 1,048,576$) yields 115.36 MiB.
