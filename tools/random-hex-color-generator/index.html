The Technical Core: Understanding HEX, RGB, and HSL Color Models

When web design systems process colors, they rely on mathematical models that map light frequencies to digital storage arrays:

1. Base-16 Hexadecimal Notation

A standard HEX color code consists of a hash symbol (`#`) followed by six hexadecimal characters grouped into three pairs. Each pair represents the intensity of Red, Green, and Blue light channels ranging from `00` (minimum intensity / absolute black) to `FF` (maximum intensity / full saturation).

2. RGB Additive Color Mixing

The RGB model mirrors how electronic displays emit light by combining red, green, and blue sub-pixels. Values range between 0 and 255 per channel. For instance, pure white is represented as `rgb(255, 255, 255)` while pure black is `rgb(0, 0, 0)`.

3. HSL (Hue, Saturation, Lightness)

While RGB aligns with hardware displays, HSL mirrors human color perception. Hue defines the color angle on a 360-degree color wheel, saturation dictates color purity from grayscale to vivid, and lightness controls brightness from dark shadow to bright highlight.

What is the difference between 3-digit and 6-digit HEX codes?

A 3-digit HEX code (e.g., `#0F2`) is shorthand for a 6-digit code where each digit is doubled (`#00FF22`). While compact, 6-digit codes provide the full 24-bit color spectrum necessary for precise design work.
