The Technical Core: Extracting System Metrics via Modern Web APIs

When you load our diagnostic utility, a comprehensive script scans multiple browser namespaces to assemble a precise profile of your hardware configuration:

1. Navigator Interface and Operating System Classification

The navigator.userAgentData and traditional navigator.userAgent strings provide deep insights into the underlying host operating system, CPU architecture, and browser engine version. By evaluating platform tokens, developers can instantly distinguish between macOS, Windows, Linux, iOS, and Android environments.

2. Hardware Concurrency and RAM Estimation

Performance-critical applications—such as client-side video editors, 3D WebGL games, and code compilers—query navigator.hardwareConcurrency to determine available CPU logical cores, and navigator.deviceMemory to estimate installed RAM capacity, allowing apps to scale their workload dynamically.

3. Screen Geometry and High-DPI Pixel Ratios

Display fidelity relies heavily on screen dimensions and device pixel ratios (DPR). By analyzing window.screen.width, window.innerHeight, and window.devicePixelRatio, developers can detect retina displays, ultra-wide monitors, and mobile viewports with absolute precision.

Frequently Asked Questions (FAQ) - Core Diagnostic Segment

Why do some browsers report approximate RAM or CPU core counts?

Modern web browsers implement privacy restrictions (such as fingerprinting mitigations) that occasionally round or cap reported hardware concurrency and device memory values. This prevents malicious scripts from uniquely identifying individual users across different web sessions.

How does screen resolution differ from active viewport size?

Screen resolution refers to the total physical or configured pixel dimensions of your monitor or display panel. Viewport size refers exclusively to the inner dimensions of the browser window area available for rendering web content, excluding browser toolbars, tabs, and operating system taskbars.

Is my diagnostic telemetry data stored or shared on external servers?

Absolutely not. Texus Pro Tools values your data privacy above all else. The Device Info Checker executes 100% client-side within your browser's local memory. No system specs, IP addresses, or user agent strings are ever transmitted or stored on external servers.
