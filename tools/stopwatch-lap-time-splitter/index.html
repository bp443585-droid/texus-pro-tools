Understanding Chronometric Metrics: Lap Time vs. Split Time

While often used interchangeably in casual communication, lap time and split time refer to fundamentally distinct components of a temporal dataset:

1. Interval Lap Time ($\Delta t$)

Lap time measures the precise interval elapsed between the start and end of a single repeated segment or loop. Mathematically, for any lap $n$, the lap time $L_n$ is expressed as:

$L_n = T_n - T_{n-1}$

where $T_n$ is the total cumulative split time at the completion of lap $n$, and $T_{n-1}$ is the cumulative split time at the completion of the preceding lap $n-1$.

2. Cumulative Split Time ($T_n$)

Split time represents the continuous total time recorded from the initial ignition event ($T_0 = 0$) up to the instant the split marker is triggered. It represents the sum of all preceding lap intervals up to that milestone:

$T_n = \sum_{i=1}^{n} L_i$

3. Interval Delta ($\delta$)

The delta indicates the relative difference in performance between the current lap and the immediate prior lap ($L_n - L_{n-1}$). A negative delta indicates acceleration (a faster lap), whereas a positive delta highlights deceleration or performance degradation.

How does this tool calculate the fastest and slowest laps?

Upon recording each lap split, the algorithm evaluates all recorded interval lap times ($L_1, L_2, \dots, L_n$). The minimal value is assigned the green Fastest status, while the maximum value receives the red Slowest tag. In the event of a tie, the earliest occurring lap retains the badge.

Does switching browser tabs cause the stopwatch to lose precision?

No. Because temporal offsets are derived from hardware timestamp differences rather than counting execution ticks, background tab throttling by the browser does not affect accuracy. When you return to the active tab, the timer instantly updates to the correct hardware duration.
